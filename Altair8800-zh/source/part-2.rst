A. 中央处理器（CPU）
================================

中央处理器（CPU）执行所有的算术运算，做出所有的逻辑判断，控制输入
和输出设备对计算机的访问，把数据存入存储器并从存储器中取出数据，
并协调程序的有序执行。CPU 实实在在是计算机的心脏。

当然，必须记住一点：CPU 的智能程度取决于程序员，因为必须用精确的
术语指示 CPU 如何执行某一特定操作。但是，由于 *ALTAIR 8800* 中的
CPU 执行一个完整的指令周期只需 2 微秒*，计算机能在极短的时间内解
决非常复杂的问题。事实上，*ALTAIR 8800* 每秒能执行约 30,000 次包
含 6 条指令的加法程序。

*ALTAIR 8800* 小巧紧凑、经济实用，很大程度上要归功于 CPU。得益于
大规模集成电路（LSI）技术，*ALTAIR 8800* 所使用的 CPU 被制造在一
小块硅芯片上，其表面积只有几分之一英寸。这款芯片就是 Intel
8080，它安装在带有 40 个引脚的保护性双列直插式封装中。

CPU 显然是 *ALTAIR 8800* 中最复杂的部分。图 2-2 给出了 CPU 的完整
框图。虽然不需要详细理解这张图，但了解 CPU 中一些较重要子系统的
功用是很重要的。这样一来，这些子系统之间的相互关系以及它们对
CPU 运行的贡献就会变得更加清楚。

1. 时序与控制\ |--|\ 时序与控制系统从时钟接收时序信号，并将其分配
   给 CPU 的相应部分，以确保指令执行的协调一致。时序与控制系统还
   会激活前面板上的若干状态指示灯（HOLD、WAIT、INTE、STACK、OUT、
   IN、INP、MI MENR、HLTA、WO、INT）。

   * 微秒是百万分之一秒。

2. 指令寄存器\ |--|\ 二进制机器语言指令暂时存放在指令寄存器中，供
   CPU 译码和执行。

3. 算术运算\ |--|\ 算术运算系统既能执行二进制算术运算，也能执行十
   进制算术运算。所有算术运算都通过加法完成。乘法通过重复加法实
   现，减法和除法通过逆加法实现。

4. 工作寄存器\ |--|\ CPU 包含 7 个 8 位工作寄存器。其中最重要的是
   累加器，许多运算的结果最终都会装入累加器。除了作为许多程序运算
   结果的主要存放点之外，累加器还可以与任一指定的寄存器或存储地址
   进行大量的算术和逻辑运算，

   其余 6 个寄存器成对排列，以便在需要时进行 16 位运算，它们是
   “暂存”寄存器。这仅仅意味着它们通常用于存放临时数据或地址，并可
   用于大量的程序运算。

   图 2-3 展示了 7 个工作寄存器的排列和分类。紧邻累加器的另一个寄
   存器是状态位寄存器，它是一个专用寄存器，用于存放某些运算的状
   态。

5. 状态位寄存器\ |--|\ 状态位寄存器是一个专用寄存器，用于存放 5 种
   状态，这些状态可能受数据运算结果的影响，也可能不受影响。该寄存
   器包含 8 个位的位置，但只有 5 位用于存放状态信息。这 5 个状态位
   是：

   a. 进位位\ |--|\ 如果发生进位，该位置 1。加法、减法、循环移位以
      及某些逻辑判断等运算通常会影响进位位。如果没有发生进位，该位
      置 0。

   b. 辅助进位位\ |--|\ 该位置 1 表示结果的第 3 位有进位。0 表示无
      进位。该状态位只受一条指令（DAA）影响。

   c. 符号位\ |--|\ 该位置位用于表示结果的正负。置 1 表示结果为
      负；置 0 表示结果为正。符号位反映结果中最高有效位（第 7 位）
      的状态。这是因为，如果用最高有效位指示结果的正负，一个 8 位字
      节能表示的十进制数范围为 -128 到 +127。23

   d. 零位\ |--|\ 如果某些指令的结果为零，该位置 1；如果结果大于
      零，则该位复位为 0。

   e. 奇偶位\ |--|\ 某些运算会检查结果的奇偶性。奇偶性表示结果中 1
      位的个数是奇数还是偶数。因此，如果 1 的个数为偶数，奇偶位置
      1；如果 1 的个数为奇数，奇偶位置 0。

6. 程序计数器\ |--|\ 程序计数器是一个特殊的 16 位寄存器，用于存放
   下一条待执行程序步骤的地址。每执行完一个步骤，程序计数器就自动
   前进到下一个顺序程序地址。程序计数器有时也称为 P 计数器，程序员
   可以通过实现 JUMP、CALL 和 RETURN 指令的机器语言指令直接访问
   它。

7. 堆栈指针\ |--|\ 堆栈指针是另一个特殊的 16 位寄存器。存储器中保
   留用于临时存放数据或地址的区域称为堆栈。

   可以通过若干条指令把数据压入堆栈临时存放，也可以从堆栈中弹出数
   据。

   堆栈指针用于在执行子程序期间保存程序计数器的内容。RETURN 指令把
   堆栈指针的内容传送给程序计数器，主程序随即继续顺序执行。程序员
   通过一条专用指令（LXI）把期望的存储地址装入堆栈指针，从而选择
   堆栈在存储器中的位置。

工作寄存器、程序计数器、堆栈指针、算术运算系统、指令寄存器以及时
序与控制系统之间的相互关系，现在应该更有意义了。工作寄存器包括 6
个暂存寄存器和 1 个累加器，大量运算结果会临时存放在累加器中。程序
计数器通过跟踪下一条待执行指令的存储地址，使程序得以顺序执行。时
序与控制系统提供时序脉冲，协调程序的有序执行。堆栈指针用于临时存
放任一寄存器对中的数据。堆栈指针还会在子程序执行前保存程序计数器
中的地址，以便子程序执行完毕后取回。所有这些操作合在一起，构成了
一个极其灵活、用途广泛的 CPU。

B. 存储器
=========

尽管工作寄存器、程序计数器和堆栈指针确实起着存储器的作用，但 CPU
并不包含计算机应用中所定义的那种存储器。计算机的主存储器位于 CPU
外部。

简单的程序用几十个字甚至更少的存储器就能实现，但像视频处理这样更
复杂的应用则需要更多存储器。*ALTAIR 8800* 的存储器最多可扩展到
65,536 个 8 位字。

存储器的访问始终由 CPU 控制。* 16 条称为地址总线的线路把 CPU 与存
储器连接起来。这些线路使 CPU 能够向任一存储地址输出数据或从任一存
储地址输入数据。地址由两个 8 位字节指定。CPU 把每个地址当作两个顺
序（串行）周期来处理，每个周期包含 8 个并行位。存放在存储器中的数
据通过 8 条称为数据总线的数据线在存储器与 CPU 之间交换。这种互连
格式支持并行操作。因此，当 CPU 从存储器读取数据或向存储器写入数据
时，数据以完整的 8 位字形式传送。

*ALTAIR 8800* 的基本存储器最多包含 8 个 256 x 4 位随机存取存储器
（RAM）。不过，只要总线上的输入负载不超过 50 个 TTL 负载，并且总
线由标准 TTL 负载驱动，计算机中可以使用任何常规存储器。

* 例外情况是计算机连接到了直接存储器访问控制器。DMA 在直接传送整
  块数据时从 CPU 接管地址线和数据线。这些传送可以在内部进行（从一
  个存储单元传送到另一个存储单元），也可以在外部进行（从存储器传送
  到外部设备）。

C. 时钟
========

CPU 对程序的有序执行由 2 MHz 晶体控制时钟控制。采用晶体控制是为了
让时钟以 CPU 所允许的最高速度运行。没有晶体调节的时钟有时可能会
加速到超出 CPU 的能力，从而导致程序执行错误。

D. 输入/输出
===============

*ALTAIR 8800* 可以与大量外部设备接口。一般来说，这些设备向计算机
提供输入信息，并接收来自计算机的输出信息。CPU 监视程序执行以及输
入/输出设备的状态，并为外部设备提供服务提供必要的信号。程序员可以
指示 CPU 忽略或响应外部设备提供的中断信号。这些中断信号一旦被 CPU
接受，就会使程序执行暂时停止，同时由计算机为该外部设备提供服务。
外部设备服务完毕后，程序恢复正常执行。*ALTAIR 8800* 最多可为 256
个输入设备和 256 个输出设备提供服务。
