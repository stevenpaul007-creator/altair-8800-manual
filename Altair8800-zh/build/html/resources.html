资源¶

如果你拥有一台 Altair 8800 克隆机，我推荐你阅读 `Altair Clone Operator's Manual``_ 以及 Support`_ 页面上的其他资源。 尤其是 **PART 2 – CONFIGURATION MONITOR**，其中详细介绍了如何 轻松加载 ``.BIN 和 .HEX 文件。

Dave Dunfield 在他的 Classic Computing 页面上提供了大量 信息，我们就是从那里获得以下资料的：

  • Assembly Language Programming System (A.L.P.S.)

  • Device Management Facility (DMF-80/ST)

此外，Atari Clone 下载站的 Manuals 页面是以下资料的来源：

  • 4kbootstrap.pdf

  • Altair 2SIO Serial I-O.pdf

  • Microsoft M80 Assembler.pdf

另外，Altair Front Panel 页面上也有不少有用的程序示例。

有位 Jeff Tranter 提供了一些关于 Macroassembler AS 的小贴士， 它需要从源代码编译，但显然能胜任工作。
