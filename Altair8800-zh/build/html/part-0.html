第 0 部分：前言：版本说明、致谢等¶

这项倾注热爱的工作由 Kevin Cole（"The Ubuntourist"）于 2020 年 9 月发起，旨在为 计算机系统课程 提供补充。

本文档的读者可以使用 Ian Davies 开发的出色 MITS Altair 8800 simulator 来测试自己的代码，或者只需 $621（US）即可拥有一台实体 Altair 8800 Clone，配有拨动开关、闪烁的红色 LED 等等。

初学者可能会觉得 YouTube 上 Patrick Jackson 的视频 相当有参考价值。

除了将 扫描印刷品 转换为可搜索的 HTML 之外，本版本还包含对原文档中排印错误的更正，以及一些补充材料，尤其涉及 半加器 电路、在 Linux 系统下汇编并加载代码的说明，以及 快进到 2020 年 —— 后者同时包含用 GNU Assembler（gas） 和 Netwide Assembler（nasm） 编写的 "Hello World"。

若要深入了解 Intel 8080 CPU，请参阅 Intel 8080 编程手册，唉，它多半不会由我转换为 HTML 了。它有*一点* 😉 太远了。

从 PDF 扫描印刷品到 HTML（以及最终更好的 PDF）的转换，是借助以下工具完成的：**pdftoppm**（poppler-utils 工具之一）、Tesseract-OCR、Inkscape、基于 Cloud 主题的 Sphinx，当然还有 `One True Editor`_（"顶礼膜拜！"）|wink|。

印刷品本身来自一座金矿：Classic Computing 网站上的 Dave Dunfield's 页面 Daves Old Computers。认真的学生和爱好者不妨戴上安全帽，去那里挖上一番。（金丝雀可选。😉）

源代码和渲染出的 HTML 托管在 Codeberg.org，因为我**真的**很喜欢他们的 使命宣言。

如果你发现了问题，可以提交 issue。

由于 Micro Instrumentation and Telemetry Systems（MITS）公司已经不复存在，我们曾尝试联系版权持有人，但可惜搜寻无果。

无论如何，原作的版权归 MITS, Inc 所有：Copyright © 1975。
