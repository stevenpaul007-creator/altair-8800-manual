#########
资源
#########

如果你拥有一台 Altair 8800 克隆机，我推荐你阅读 `Altair
Clone Operator's Manual``_ 以及 ``Support`_ 页面上的其他资源。
尤其是 **PART 2 – CONFIGURATION MONITOR**，其中详细介绍了如何
轻松加载 ``.BIN`` 和 ``.HEX`` 文件。

`Dave Dunfield`_ 在他的 `Classic Computing`_ 页面上提供了大量
信息，我们就是从那里获得以下资料的：

* `Assembly Language Programming System (A.L.P.S.)`_
* `Device Management Facility (DMF-80/ST)`_

此外，Atari Clone 下载站的 `Manuals`_ 页面是以下资料的来源：

* `4kbootstrap.pdf`_
* `Altair 2SIO Serial I-O.pdf`_
* `Microsoft M80 Assembler.pdf`_

另外，`Altair Front Panel`_ 页面上也有不少有用的程序示例。

有位 `Jeff Tranter`_ 提供了一些关于 `Macroassembler AS`_ 的小贴士，
它需要从源代码编译，但显然能胜任工作。
