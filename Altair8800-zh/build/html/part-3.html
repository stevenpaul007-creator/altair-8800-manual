第 3 部分：ALTAIR 8800 的操作¶

基本型 ALTAIR 8800 通过前面板进行操作。乍一看，25 个拨动开关和 36 个指示及状态 LED 的阵列可能令人困惑。实际上，ALTAIR 8800 的操作非 常直接，大多数用户不到一小时就能学会把程序装入机器并运行它。如果你 是典型用户，你花在开发和编写程序上的时间将远远超过实际操作机器的时 间。

ALTAIR 8800 操作手册的这一部分介绍前面板开关以及指示和状态 LED 的 用途和应用。接着把一个示例程序装入机器并运行。随后详细讨论存储器的 作用和有效使用。最后给出几条操作提示，帮助你编辑和“调试”程序。

A. 前面板开关与 LED¶

尽管前面板包含 25 个拨动开关和 36 个指示及状态 LED，但基本型 ALTAIR 8800 （256 字存储器）的大多数常规操作只需使用 15 个开关并监 视 16 个 LED 即可完成。下面说明所有开关和 LED 的功能：

1. 前面板开关¶

ON-OFF 开关

ON 位置为计算机接通电源。OFF 位置切断电源，同时也会清除 存储器的内容。

STOP-RUN 开关

STOP 位置停止程序执行。RUN 位置执行程序。

SINGLE STEP 开关

每拨动一次该开关，就执行一条机器语言指令。一条机器语言指令最多 可能需要 5 个机器周期。

EXAMINE-EXAMINE NEXT 开关

EXAMINE 位置在 8 个数据 LED 上显示先前通过 DATA/ADDRESS 开关（见下文）装入的任何指定存储地址的内容。EXAMINE NEXT 位 置显示下一个顺序存储地址的内容。每拨动一次 EXAMINE NEXT，都 会显示下一个顺序存储地址的内容。

DEPOSIT-DEPOSIT NEXT 开关

DEPOSIT 位置把装入 8 个 DATA 开关的数据字节装入先前指定 的存储地址。DEPOSIT NEXT 位置把装入 8 个 DATA 开关的数据 字节装入下一个顺序存储地址。每拨动一次 DEPOSIT NEXT，装入 8 个 DATA 开关的数据字节就会被装入下一个顺序存储地址。在拨动 DEPOSIT 或 DEPOSIT NEXT 之前，可以更改装入 8 个 DATA 开关的数据字节。

RESET-CLR 开关

RESET 位置把程序计数器设置为第一个存储地址（0 000 000 000 000 000）。对于从第一个存储地址开始的程序，RESET 提供了一种 快速有效的方法回到程序的第一步。CLR 是用于外部输入/输出设备 的 CLEAR 命令。

PROTECT-UNPROTECT 开关

PROTECT 位置防止存储器内容被更改。UNPROTECT 位置允许更改 存储器的内容。

AUX 开关

基本型 ALTAIR 8800 带有两个辅助开关，它们尚未连接到计算机。这 些开关将与添加到基本机器上的外部设备配合使用。

DATA/ADDRESS 开关

DATA 开关是指定为 7-0 的那些开关。ADDRESS 开关是指定为 15-0 的那些开关。拨动开关处于 UP 位置表示 1 位。拨动开关处于 DOWN 位置表示 0 位。在基本型 ALTAIR 8800 （256 字存储器） 中，指定为 8-15 的 ADDRESS 开关不使用，输入地址时应将其置 0。

2. 指示 LED¶

备注

机器停止时，点亮的 LED 表示 1 位或指定条件的活动状态；未点亮的 LED 表示 0 位或非活动状态。但是，在运行程序时，LED 的显示可能 看起来不正确。

LED

定义

ADDRESS

ADDRESS LED 是指定为 A15-A0 的那些。ADDRESS LED 上显示的位模式表示所检查 或装入数据的存储地址。

DATA

DATA LED 是指定为 D7-DO 的那些。DATA LED 上显示的位模式表示指定存储地 址中的数据。

INTE

该 LED 点亮时，表示中断（INTERRUPT）已允许。

PROT

该 LED 点亮时，表示存储器已处于保护（PROTECTED）状态。

WAIT

该 LED 点亮时，表示 CPU 处于等待（WAIT）状态。

HLDA

该 LED 点亮时，表示 HOLD 已获确认（ACKNOWLEDGED）。

3. 状态 LED¶

备注

点亮的 LED 表示指定条件处于活动状态。

LED

定义

MEMR

存储器总线将用于存储器读数据。

INP

地址总线上含有输入设备的地址。当数据总线处于输入模 式时，输入数据应放到数据总线上。

M1

CPU 正在处理一条指令的第一个机器周期。

OUT

地址总线上含有输出设备的地址；当 CPU 就绪时，数据总线上将包 含输出数据。

HLTA

一条 HALT 指令已执行并得到确认。

STACK

地址总线上保存着堆栈指针的下压堆栈地址。

WO

当前机器周期将执行 WRITE 存储器或 OUTPUT 功能。否 则，将执行 READ 存储器或 INPUT 操作。

INT

一个 INTERRUPT 请求已被确认。

B. 载入示例程序¶

第 1 部分 G 节介绍了一个用机器语言助记符编写的简单加法程序。该程序 旨在从存储器中取出两个数，把它们相加，并把结果存入存储器。用助记符 形式表示，该程序可以这样写：

  1. LDA

  2. MOV (A→B)

  3. LDA

  4. ADD (A+B)

  5. STA

  6. JMP

ALTAIR 8800 全部 78 条指令的助记符在本手册第 4 部分中有详细说 明。目前，以下定义已经足够：

  1. LDA–把指定存储地址的内容装入累加器。

  2. MOV (A→B)–把累加器的内容传送到寄存器 B。

  3. ADD (B+A)–把寄存器 B 的内容加到累加器的内容上，并 把结果存入累加器。

  4. STA–把累加器的内容存入指定的存储地址。

  5. JMP–跳转到程序的第一步。

备注

计算机执行完程序后，会在存储器中寻找其他可做的事情。为了保持对 CPU 的控制，我们可以用一条 JMP 指令（后跟第一条指令的存储地 址）来结束示例程序。计算机将“跳转”回示例程序的第一条指令，一遍 又一遍地执行该程序。

注意这些指令每一条是多么精确和具体。计算机被 确切地 告知如何解 决问题以及把结果放到哪里。这些机器语言指令每条都需要一个单字节位 模式来实现基本指令。LDA 和 STA 还需要两个额外字节来提供必 要的存储地址。

要把这个程序装入 ALTAIR 8800，必须先确定两个待相加的数、结果以 及程序本身的存储地址。在大多数情况下，从第一个存储地址（0）开始存 放新程序会更方便。因此，数据（两个待相加的数和结果）的存储地址应放 在存储器中较高的任意地址上。由于基本型 ALTAIR 8800 有 256 字存储 器，我们选择从存储地址 128 开始存放数据。第一个加数放在存储地址 128（10 000 000），第二个加数放在存储地址 129（10 000 001），结果放 在存储地址 130（10 000 010）。存储地址确定后，就可以把程序转换成它 的机器语言位模式了：

程序现在可以运行了，但首先必须在两个待相加的存储地址中存入数据。要 装入第一个地址，把 DATA/ADDRESS 开关设置为 10 000 000 并拨动 EXAMINE。现在可以通过相应设置 DATA/ADDRESS 开关，把任何期 望的数值装入该地址。数值装入开关后，拨动 DEPOSIT 把它装入存储 器。要装入下一个地址，在 DATA/ADDRESS 开关上输入第二个数并拨动 DEPOSIT NEXT。由于选择的是顺序存储地址，该数将自动装入正确的地 址（10 000 001）。如果选择的是非顺序存储地址，则必须遵循查找第一个 地址的过程（把地址装入 DATA/ADDRESS 开关并拨动 EXAMINE；然 后把数值装入 DATA/ADDRESS 开关并拨动 DEPOSIT）。

要检验自己装入和运行这个程序的能力，请尝试更改两个加数和结果的存储 地址，然后再次装入并运行该程序。

C. 存储器的使用¶

到现在应该很清楚，存储器在计算机的高效运行中起着至关重要的作 用。高级语言编译器通常带有一个软件包，自动跟踪各个存储地址。然 而，机器语言操作要求程序员自己跟踪存储器。否则，宝贵的数据或程序 指令可能会被意外擦除，或被其他数据或指令替换。

可以通过一种称为 存储器映射 的简单技术来跟踪 ALTAIR 8800 存储 器中存放的内容。这种技术只是把各种类型的数据分配给为特定目的保留 的特定存储块。该技术能有效地把可用存储器组织成一个高效且易于访问 的存储介质。

对于拥有 256 字存储器的 ALTAIR 8800，典型的存储器映射可能把前 100 字分配给程序，第二个 100 字分配给子程序，剩下的 56 字分配给数 据。当然，各个存储块可以随意修改，存储器映射的主要目的是对可用存 储器进行有组织的统一规划。

每次更改 ALTAIR 8800 中的程序时，都可以制作一份存储器映射。程序 写好后，决定应为程序本身、子程序（如果有）和数据保留多少存储空 间。然后制作一个表格或图表，记录各项内容存放在存储器的什么位置。 存储器组织更改时，务必更新该表格。

D. 存储器寻址¶

ALTAIR 8800 的机器语言指令集提供了多种存储器寻址方式，包括直接 寻址、寄存器对寻址、堆栈指针寻址、立即寻址以及子程序的堆栈寻 址。下面介绍这几种寻址方式。

  1. 直接寻址–指令以两个字节的形式提供指定的存储地址，这 两个字节紧跟在实际指令字节之后。

  2. 寄存器对寻址–寄存器对的内容可以存放存储地址。在大多 数指令中，必须为此使用 H 和 L 寄存器。H 寄存器存放最 高有效 8 位，L 寄存器存放最低有效 8 位（H 为 高， L 为 低）。两条指令（STAX 和 LDAX）允许 B 和 C 或 D 和 E 寄存器对存放存储地址。

  3. 堆栈指针寻址–堆栈操作只有两种：PUSH 和 POP。把数据 PUSH 到堆栈上，会把两个字节（16 位）数据存入程 序员保留的、称为堆栈的特定存储块。从堆栈中 POP 数据则会取出这些 数据。PUSH 和 POP 指令在本手册 第 4 部分 中有详细说 明。目前必须知道的是，程序员 必须 通过把存储地址装入堆栈指针 来保留存储器中的堆栈位置。这通过 LXI 指令实现（见 第 4 部分）。程序员应始终在自己的存储器映射上记下堆栈的地 址。

  4. 立即寻址–立即寻址指令包含在程序装入期间装入存储器的 数据。由于数据与程序一起按顺序装入，它存放在操作者为程序保留的 存储块中。装入立即数时无需更改存储器映射。

  5. 子程序的堆栈寻址–当程序调用（CALL）一个子程序时，主 程序中下一条顺序指令的地址会自动地通过压入（PUSH）堆栈保存。子 程序执行完毕后，RETURN 指令从堆栈弹出（POP）该地址，主程序继续 执行。

E. 操作提示¶

随着你对 ALTAIR 8800 操作经验的积累，你会想出一些方法来提高程序 的效率和计算机的运行水平。下面列出了几条有用的提示，在学习操作这 台机器时你会发现它们非常有用。

  1. 校对程序–为了安全起见，程序输入计算机后一定要进行校 对。方法是回到程序开始的第一个存储地址（如果程序从存储单元 0 开 始，拨动 RESET；否则在 ADDRESS 开关上设置地址并拨动 EXAMINE），检查 DATA LED，确认第一步程序已正确输入。然 后拨动 EXAMINE NEXT，对照 DATA LED 检查第二步。以这种方 式继续校对，直到检查完整个程序。如果发现错误，只需在 DATA 开 关上重新输入正确的位模式，拨动 DEPOSIT，然后继续用 EXAMINE NEXT 开关进行校对。

  2. 使用 NOP–NOP 是一条指定“无操作”的指令，看起来没 什么价值。但是，如果在复杂程序中散布 NOP 指令，那么当发现需 要添加新步骤的程序错误时，可以节省大量时间。在程序校对期间，只 需把新指令或数据输入到 NOP 指令的位置上即可。如果觉得某条新 指令可能是必要的，务必使用适当数量的 NOP。例如，如果你认为 程序执行不正常时可能需要添加一条 LDA 指令，就在需要的位置连 续使用三条 NOP。需要三条 NOP 是因为 LDA 指令需要三 个独立的字节。

  3. 调试程序–有时需要对程序进行“调试”。当程序因错误 （bug）而无法正常执行时，就需要调试。使用 SINGLE STEP 开关可 以帮助调试。该开关让计算机按机器周期（而不是完整的程序步骤）步 进执行程序，使你能观察 8 个 STATUS LED 的状态。这个过程能让 你发现非法输入、程序组织不当以及其他编程错误。
